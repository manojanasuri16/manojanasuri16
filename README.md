### What I'm building lately

Lately I've been spending my time building and shipping real apps, mostly private, offline-first Android apps, and publishing them for friends and family.

**[AppDrop](https://github.com/manojanasuri16/AppDrop)** is my personal app store. It's a Next.js 16 + SQLite/Drizzle app that publishes Android APKs (via GitHub Releases) and web apps in one installable PWA store. It has in-app update checks, push notifications for new releases, feedback forms, beta invite links, download insights, and daily backups. [Open the store](https://appdrop-six.vercel.app)
